02 / 本地优先

不注册，也能安心记。

目前版本不连接云端数据库。每个人安装后拥有独立的数据空间，待办、日程、笔记和头像默认只留在自己的电脑里。

  • 不会自动共享你和朋友下载同一个应用，看到的仍是各自的数据。
  • 没有账号门槛打开就能使用，不需要手机号、邮箱或登录。
  • 测试版请记得备份卸载应用或清理应用数据可能会丢失本地记录。
